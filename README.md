
# Bolsones Familiares

## Política de privacidad y eliminación de datos personales

Bolsones Familiares es un servicio de venta y entrega a domicilio de frutas y verduras que puede utilizar WhatsApp para comunicarse con sus clientes y gestionar pedidos.

### Política de privacidad

La política de privacidad informa qué datos personales se pueden recopilar, cómo se utilizan, con quién pueden compartirse y durante cuánto tiempo se conservan.

**Consultar la política de privacidad:**

https://bolsonesfamiliares-design.github.io/politica-privacidad-bot/

### Solicitud de eliminación de datos

Los usuarios pueden solicitar la eliminación de sus datos personales asociados al servicio.

Para realizar una solicitud:

1. Enviar un correo electrónico a bolsonesfamiliares@gmail.com.
2. Escribir como asunto: `Solicitud de eliminación de datos`.
3. Indicar el número de teléfono utilizado para comunicarse con Bolsones Familiares.
4. Solicitar expresamente la eliminación de los datos personales.

Se podrá solicitar información razonable para verificar la identidad del solicitante.

Las solicitudes serán revisadas y gestionadas conforme a la legislación aplicable. Los datos que deban conservarse por obligaciones legales podrán quedar exceptuados de la eliminación mientras exista dicha obligación.

**Página de instrucciones para eliminar datos:**

https://bolsonesfamiliares-design.github.io/politica-privacidad-bot/eliminacion-datos.html
